## BRACOL: what we actually found (inspected 2026-10-03)

- **Leaf side and setting:** photos of the **abaxial (lower) side** of single detached leaves on a **white background**, taken with five smartphone models (ASUS Zenfone 2, Xiaomi Redmi 5A, Xiaomi S2, Galaxy S8, iPhone 6S). Images are 2048×1024 landscape with the leaf lying horizontally.
- **Origin:** Santa Maria de Marechal Floreano, mountain region of Espirito Santo, Brazil.
- **Label file:** `leaf/dataset.csv`, columns `id, predominant_stress, miner, rust, phoma, cercospora, severity`.
- **Stress codes:** 0 healthy, 1 leaf miner, 2 leaf rust, 3 phoma (brown leaf spot), 4 cercospora leaf spot. Mapping confirmed from the authors' code ([esgario/lara2018](https://github.com/esgario/lara2018), symptom folders `1_health … 5_cercospora`).
- **Code 5 (62 rows):** not documented. These rows have mixed or no secondary stress flags, and the authors' own `dataset.csv` (1,685 rows) excludes them. We exclude them too. `TODO: verify` the meaning of code 5 with the authors.
- **Severity codes** (from the dataset description, % of leaf area with symptoms): 0 healthy (< 0.1%), 1 very low (0.1–5%), 2 low (5–10%), 3 high (10–15%), 4 very high (> 15%).
- **Truncated Mendeley archive:** the published zip (`BRACOL_coffee_leaf_ images_datasets.zip`, 164,516,964 bytes, sha256 `25a2fc97…fdfc1f`) matches Mendeley's own published hash but ends partway through a file. Only 1,401 of the 1,747 leaf images extract intact (`688.jpg` is cut off), and the symptom dataset is absent entirely. The label file `leaf/dataset.csv` is complete.
- **GitHub copy:** the authors' repo has all 1,747 leaf images. They are **preprocessed**: cropped tight to the leaf's bounding box and resized to 512×256, so aspect ratio is not preserved. Checks run by `ml/prepare_data.py` and by hand on 2026-10-03:
  - The repo's `dataset-full.csv` is byte-identical to the Mendeley `dataset.csv`.
  - Every one of the 1,747 label ids has exactly one decodable crop, and there are no unlabelled crops.
  - The ids refer to the same leaves. We cropped each of the 1,401 intact Mendeley originals to the leaf and compared it with the GitHub crop of the same id. Median grey-level correlation was 0.993, against 0.671 for a control pairing each image with the next id. The 5 lowest-scoring pairs were inspected visually and are the same leaf (the low scores came from our crude crop on grey backgrounds).
  - Bytes differ, because the authors re-encoded them.
- **Which images we train on:** all 1,685 usable images use the GitHub crops, so the whole set shares one format. Mixing uncropped Mendeley originals with GitHub crops would have created a framing shortcut, because the missing images are mostly healthy (130 of 343). The app crops each photo to the leaf's bounding box before inference to match this format.
- **Split:** the dataset ships no split files. `ml/prepare_data.py` makes a **stratified (by stress) 70/15/15 split with seed 150** (the seed used in the authors' code) and saves it to `ml/data/splits/`:

Stress × severity over the 1,685 images:
- Healthy is always severity 0, and a diseased leaf is never 0.
- Miner never reaches "very high" (279 / 84 / 24 / 0 across very low / low / high / very high).
- Cercospora is almost all "very low" (129 of 147).
- Only rust and phoma have meaningful numbers of "very high" leaves (39 and 16).

## What the data does not cover

- BRACOL is **Brazilian**. It does not include Kenyan or East African varieties (for example SL28, SL34, Ruiru 11) or highland Kenyan field conditions.
- **No nutrient-deficiency class.** Yellowing from nitrogen deficiency is not a trained label and should fall through to "not sure". This is not guaranteed: the model can still be confidently wrong on unseen conditions.
- Images are **single detached leaves on a white background**, photographed from the lower side. They are not leaves on the tree, not cluttered backgrounds, and not the upper side.
- **No abiotic stress labels** (drought, frost, sunscald).
- Several biotic stresses can co-occur on one leaf, but the label records only the predominant one.
- Severity classes are imbalanced: few "high" or "very high" examples, and almost none for cercospora.
- The cooperative registry, plot points, and outbreak reports in the demo are **synthetic**. Only the area the points sit in is real.
- Rainfall and soil context come from **coarse global grids**, not plot-level measurement.
